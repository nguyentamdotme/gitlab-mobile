# gitlab-mobile

Ứng dụng mobile GitLab dự kiến dùng React Native + Expo + TypeScript, ưu tiên phiên đăng nhập an toàn và vận hành CI/CD qua API.

## Kế hoạch

- [Kịch bản sử dụng, kiến trúc và roadmap](plans/20261004-1731-gitlab-mobile/plan.md)
- [Hợp đồng API và giới hạn tương thích](plans/20261004-1731-gitlab-mobile/api-contract.md)
- 7 phase triển khai với tasks, file ownership và tiêu chí nghiệm thu trong cùng thư mục kế hoạch.

**Trạng thái:** mới lập kế hoạch; chưa có app source, dependency, native build hoặc deployment. Test commands trong kế hoạch là scripts sẽ tạo khi triển khai, không phải checks đã chạy.
